# SlamFrames 2.0

SlamFrames 2.0 is a major feature release for the OctoWoW / Vanilla 1.12-style client environment.

Highlights include predictive healing, the new Ornate cast bar, robust cast pushback and interruption handling, refreshed aura-duration reconciliation, special two-layer Rare/Elite/Boss portrait frames, mirrored optional Player decorations, Light/Dark special-frame assets, and independent Player/Friendly/Enemy/Rare-Elite name-position controls.

For the packaged addon, attach the final `SlamFrames-v2.0.zip` asset to the GitHub Release.
