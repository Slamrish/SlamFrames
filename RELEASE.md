# SlamFrames 3.3 — Release Notes

SlamFrames 3.3 extends the Vanilla-era unit-frame system with Rogue/Druid combo-point trackers, improved Focus-frame health presentation, reliable clean click-cast defaults for newly created characters, and more consistent object-interaction cast text.

### Highlights

- Custom Player combo-point bars for Rogues and Druids, including separate normal, Rare/Elite and Boss variants for Light and Dark skins
- Target combo arc attached to the SlamFrames Target portrait, with its own size and visibility controls
- Dark backing for empty Focus health and matched Focus health fill/depletion geometry in both skins
- Light-skin combo gem fill alignment refinements
- New characters receive blank Normal click-cast bindings without inheriting previously used spell/item names
- Old-client world interactions receive clean activity names rather than verbose target-dependent sentences
- Clear Player versus Target combo controls in settings
- Cast-bar choices remain **V1** and **Ornate**

### Installation

Download `SlamFrames-3.3.zip`, extract, and copy `SlamFrames` into `World of Warcraft\Interface\AddOns\`. The installed folder must contain `SlamFrames.toc` at its top level. Replace existing SlamFrames addon folders rather than merging. SavedVariables are stored outside the addon folder.

Supports OctoWoW and compatible Vanilla 1.12-style clients; not Retail or modern Classic.
