# SlamFrames 2.5

SlamFrames 2.5 is the current stable release for OctoWoW / Vanilla 1.12-style clients.

## Highlights

- Cast-state isolation fixes the bandage/channel timing contamination that could corrupt later Throw, Hearthstone, Shoot, Cooking, crafting, and other cast bars until reload.
- Dynamic UI layering keeps SlamFrames above world/nameplate frames during gameplay and below Blizzard panels when they are open.
- Correct Vanilla player-level-dependent enemy difficulty/gray coloring.
- Target aura numeric timer layer locking for more reliable long-session display.
- Cleaner Ornate Mining flavor text.
- Includes all SlamFrames 2.0 features: predictive healing, Rare/Elite/Boss portrait frames, aura refresh reconciliation, independent name positioning, Light/Dark themes, and the Ornate cast bar.
