SlamFrames 2.5.1 - OctoWoW / Vanilla 1.12-style replacement unit frames

SlamFrames 2.5.1 is a clean-install hotfix for the 2.5 release.
It includes all SlamFrames 2.5 features and fixes while correcting the
texture/package layout required by fresh installations.

Install:
1. Close World of Warcraft.
2. Extract the SlamFrames folder into Interface\AddOns\
3. Verify Interface\AddOns\SlamFrames\SlamFrames.toc exists.
4. Launch OctoWoW and enable SlamFrames.
5. Open settings with /sf settings or the minimap button.

Version: 2.5.1
Repository: https://github.com/Slamrish/SlamFrames
